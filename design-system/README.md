# Design System

Generated by the **UI/UX Pro Max** skill (`.claude/skills/ui-ux-pro-max`), then corrected
and extended. This directory is the single source of truth for the project's visual
language; no component may hardcode a colour, size, or font outside these tokens.

## Layout

| Path | Role |
|---|---|
| `souk/MASTER.md` | Global rules — colour, typography, spacing, shadows, component specs, style, motion, anti-patterns, pre-delivery checklist. |
| `souk/pages/*.md` | Page-level overrides. **Read the page file before building that page.** If it exists its rules override MASTER.md; otherwise MASTER.md applies. |
| `scripts/check-contrast.py` | Machine-verifies every colour pair in both themes against WCAG 2.1. Run it whenever a token changes. |

Page files present: `landing`, `product-listing`, `product-detail`, `checkout`,
`admin-dashboard`.

## Decisions taken

Presented for approval; answered "no preference", so these are the standing assumptions.
Each is cheap to reverse — say the word.

| Decision | Chosen | Rejected alternative |
|---|---|---|
| Palette | **E-commerce Luxury** — `#1C1917` near-black, `#A16207` gold, `#FAFAF9` warm off-white | The auto-selected emerald `#059669` + orange `#EA580C` on a mint `#ECFDF5` page. Both its CTA colours require black text (white fails at 3.6:1), the mint tints every screen, and its style profile targets "gaming, youth-focused". |
| Typography | **IBM Plex Sans Arabic + Inter**, both variable, via `next/font/google` | Noto Naskh + Noto Sans Arabic (the database's only Arabic pairing) — traditional calligraphic, weak Latin coverage. |
| Style | **Minimalism & Swiss Style** | Liquid Glass (auto-selected) — `risk:conditional`, blur-driven. |
| Currency | **TND**, three decimals, stored as integer minor units | Read from `SiteSetting`, so MAD / DZD / EUR are a settings change, not a code change. |
| Stock | **Block and decrement inside the order transaction** | Backorders; cart-level reservation with timeout. |
| Store name | **Souk** — a placeholder living in `SiteSetting` | Any name; changing it touches one database row. |

## Corrections applied to generated output

The generator produced these; each was wrong and was fixed in place.

1. **`.btn-primary` failed AA.** White label on `--color-accent` is 3.56:1 in the emerald
   palette. The token table said `On Accent = #000000` (5.90:1) — the CSS contradicted it.
   *(The luxury palette's white-on-gold is 4.92:1 and passes; the emerald build had the bug.)*
2. **`.card` used the page background.** `background: #FAFAF9` is `--color-background`,
   not `--color-card` (`#FFFFFF`) — cards would have been invisible. Fixed in both builds.
3. **`.input` border was 1.3:1.** `#E2E8F0` is a decorative grey; a form control's border
   is the only indicator of the control and needs 3:1 (WCAG 1.4.11). Added a dedicated
   `--color-input` token, `#8C8681` light / `#78716C` dark.
4. **`--muted` was cool slate inside a warm stone ramp.** `#E8ECF0` / `#475569` retoned to
   `#F5F5F4` / `#57534E`.
5. **`--destructive` `#DC2626` is 4.06:1 with white**, below AA. Darkened to `#B91C1C` (6.47:1).
6. **No dark mode palette was generated.** A full second palette was authored and verified.
7. **Style and typography overridden** as recorded in the table above and in MASTER.md's header.
8. **Page override stubs replaced.** The generated `landing.md` prescribed an 800px
   single-column centred layout and "A/B test colour variations per segment" — neither
   applies to a product catalogue. All five files were rewritten with real, project-specific
   rules covering layout, grid, states, motion, and RTL.

`--color-border` is intentionally *not* held to 3:1. It is a hairline between surfaces
already distinguished by their own background, so WCAG 1.4.11 does not apply. Functional
boundaries use `--color-input`.

## Tooling status

- **UI/UX Pro Max** — installed at `.claude/skills/` via `npx ui-ux-pro-max-cli init --ai claude`.
  The `/plugin marketplace` route is a CLI-interactive command unavailable to this session;
  the CLI installer is the documented fallback and produced the same skill payload.
  Verified working: `search.py` returns rows from the style, colour, typography, ux and
  `stacks/nextjs` databases.
- **21st.dev MCP** — **not connected.** `TWENTYFIRST_API_KEY` is not set in this
  environment and `claude mcp list` reports no servers. Adding the server without a key
  would register a component that fails on first call. Until a key is provided, UI
  primitives come from **shadcn/ui** (already in the stack), composed against these tokens.
  To enable it later, set the key and run:
  ```bash
  claude mcp add --transport http 21st https://21st.dev/api/mcp \
    --header "x-api-key: $TWENTYFIRST_API_KEY"
  ```
  Keep the key in `.env.local` (git-ignored). Do not write it into `.mcp.json`.
