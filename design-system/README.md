## Manual corrections applied to the generated MASTER.md

The generator emitted two component snippets that contradicted its own token table.
Both were corrected in place:

1. `.btn-primary` used `color: white` on `--color-accent` (`#EA580C`) — **3.56:1**, below the
   4.5:1 AA floor, and contradicting `On Accent = #000000` (5.90:1). Changed to `#000000`.
2. `.card` used `background: #ECFDF5`, which is `--color-background`, not `--color-card`
   (`#FFFFFF`). Cards would have been invisible against the page. Changed to `#FFFFFF`.
